## Meldungen

### [Relevanz: 4/5] Zero-Click-RCE-Lücke „Plugin4Shell" in KI-Coding-Agenten — GitHub Copilot weiterhin ungepatcht (Nachtrag)
**Kategorie:** Copilot
**Was ist passiert:** Sicherheitsforscher von AIR Security (Or Nevo, Dor Granat, Niv Hoffman) haben am 17.09.2026 mit „Plugin4Shell" eine Schwachstelle offengelegt, die die SHA-Commit-Fixierung bei Plugin-/Erweiterungsinstallationen in vier verbreiteten KI-Coding-Agenten aushebelt: Anthropic Claude Code, OpenAI Codex, GitHub Copilot und Google Gemini CLI. Ein Angreifer mit Kontrolle über ein bereits vertrautes Plugin-Repository kann über einen Branch-Namen, der dem festgeschriebenen Commit-Hash entspricht, eine bösartige Version ausliefern, die der Agent ohne jede Nutzerinteraktion als geprüft akzeptiert und mit den lokalen Rechten des Agenten ausführt (potenzieller Zugriff auf Quellcode, Cloud-Credentials, SSH-Keys, interne Systeme). Anthropic (Claude Code 2.1.179) und OpenAI (Codex 0.146.0) haben umgehend gepatcht, Google patcht das ohnehin abgekündigte Gemini CLI nicht mehr — Microsoft hat für GitHub Copilot bislang keinen Fix veröffentlicht, obwohl der Hersteller laut den Forschern bereits im Juni 2026 informiert wurde; auch eine offizielle Sicherheitsmitteilung fehlt weiterhin (Stand 25.09.2026). Das Risiko betrifft konkret Plugin-Installationen über Drittanbieter-Marketplaces (Bitbucket, GitLab, selbstgehostete Git-Server); GitHubs eigener Marketplace blockiert die zugrunde liegende Branch-Namenstechnik und gilt laut den Forschern als weniger exponiert.
**Bedeutung für DB E&C:** Relevant für die Copilot-Sicherheits- und Admin-Governance, sofern GitHub Copilot mit Plugin-/Agenten-Erweiterungen im Einsatz ist — ein reales Restrisiko für Quellcode- und Credential-Zugriff besteht, solange kein Microsoft-Patch vorliegt. Diese bereits am 17./18.09.2026 bekanntgewordene Lücke wurde in den Briefings der Vorwoche noch nicht erfasst und wird hiermit nachgetragen, da sie für GitHub Copilot weiterhin ungelöst und damit aktuell relevant ist.
**Quelle:** [AIR Security — Plugin4Shell (Originaldisclosure)](https://www.air.security/blog-posts/plugin4shell) (in dieser Umgebung technisch nicht direkt abrufbar), inhaltlich übereinstimmend bestätigt über [heise online, 21.09.2026](https://www.heise.de/en/news/Critical-flaw-in-Claude-Code-OpenAI-Codex-GitHub-Copilot-and-Gemini-CLI-11460259.html), [The Hacker News](https://thehackernews.com/2026/09/plugin4shell-lets-repository-owners.html) und [Help Net Security, 18.09.2026](https://www.helpnetsecurity.com/2026/09/18/plugin4shell-ai-coding-agents-vulnerability/)
